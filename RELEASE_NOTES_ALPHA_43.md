# StreamPulse Core 0.1.0-alpha.43

Customize Top Likes font colors under Like Rankings > Overlay appearance for better visibility against your scene.

- Separate color pickers for names and labels, like counts, and the top supporter (including tied leaders).
- Reset font colors restores the default palette.
- Colors save automatically and update existing browser sources and the preview without changing the URL.
- Existing settings and backups without color fields use defaults. Invalid overlay colors safely fall back to defaults.

Validation: production build, both TypeScript checks, release regression suite, settings persistence/restore, and hidden-browser checks for live colors, leader colors, reload persistence and invalid-color fallback. Overlay previews reviewed before publication. Installer archive and update metadata checked before publication.

The installed alpha 42 to alpha 43 update and real LIVE Studio checks remain for user verification. This alpha installer remains unsigned.
