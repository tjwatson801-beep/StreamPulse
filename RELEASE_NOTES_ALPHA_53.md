# StreamPulse alpha.53 — compact moment selection

Golden Moments replaces the scrolling suggestion list with a dropdown beside the source player. Each option shows the original moment number, source timestamp, category and detection method. Previous/Next navigate the filtered list without changing the page position.

Category/method filters remain available. The selector shows matching/total counts, handles empty filters, and retains the current reviewed cut if it falls outside a new filter. Details for the current moment and the timestamp label remain visible. On smaller windows the selector stacks above the player.
