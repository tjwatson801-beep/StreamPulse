# StreamPulse alpha.52 — edited clip playback

Golden Moments adds **Preview edited clip**. It renders a temporary video with the selected cut, framing/camera focus, generated captions, gold highlights and audio polish, then plays it inside StreamPulse without asking for an export destination.

Changing the cut, imported recording, captions or style clears the old preview. Preview generation shows progress and supports cancellation. The source recording is preserved; export remains a separate action. Generate caption words before previewing if you want captions included.

Preview rendering takes time, much like export. The engine retains up to three temporary previews and attempts cleanup on exit. This previews the selected clip, not an entire montage batch.
