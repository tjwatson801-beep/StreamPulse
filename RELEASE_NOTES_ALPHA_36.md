# StreamPulse Core Alpha 36

- Adds an overlay library to the Overlay page with separate browser-source URLs.
- Like celebrations repeat at configurable milestones for each viewer, using the Like Rankings session counts.
- Gift highlights show completed combos with gift artwork, sender, and quantity. Saved artwork fills in missing event images.
- Gift filters support exact names and minimum combo quantity.
- Both overlays offer Neon glow, Minimal card, and Spotlight styles, accent colors, duration controls, live previews, and test buttons.
- New live alerts start disabled; enable each overlay in the library. Test buttons work while disabled.
- Queues isolate the new overlays from existing Gift and Super Fan alerts.

Validation: builds, TypeScript checks, overlay trigger tests, hidden-browser artwork and delivery checks, and existing reaction, connection, likes, and alert regression tests passed during development.
