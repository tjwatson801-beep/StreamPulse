# StreamPulse alpha.48 — caption font choices

Golden Moments adds Impact, Cooper Black, Berlin Sans FB Demi, Showcard Gothic and Arial alongside Bauhaus 93, Arial Rounded MT Bold and Segoe UI. A live “Stay Golden!” sample shows the selected font and gold highlight setting.

The selected font is used in exported captions. Fonts are read from this computer; fonts that are not installed use a fallback. All eight choices were found installed on the development PC.

Local caption setup and camera-focused exports work as in alpha.47. This is a local installer, not a published GitHub release.
